# 🚗 Global Electric Vehicle Market Analysis Dashboard

A professional end-to-end Data Analytics project built using **Python** and **Power BI** to analyze global Electric Vehicle (EV) market trends from **2010–2025**.

This project demonstrates the complete analytics workflow—from data cleaning and preparation in Python to interactive dashboard development in Power BI.

## 🎯 Project Objective

The objective of this project is to analyze the growth of the global Electric Vehicle market and provide actionable insights through an interactive dashboard.

The dashboard enables users to explore EV adoption trends, compare countries, analyze powertrain distribution, and evaluate the overall growth of the EV industry.

## 🔄 Project Workflow

### 1. Data Collection
- Imported the Global EV dataset from the International Energy Agency (IEA).

### 2. Data Cleaning (Python)
Performed data preprocessing using Python:
- Removed unnecessary records
- Filtered historical EV data
- Selected relevant parameters
- Cleaned null values
- Prepared the dataset for Power BI analysis

### 3. Dashboard Development (Power BI)
Designed an interactive dashboard with:
- KPI Cards
- Trend Analysis
- Top EV Markets
- Country Comparison
- BEV vs PHEV Distribution
- Interactive Slicers

---

## 📈 Dashboard Features

### 🚗 Global EV Sales
Displays total global electric vehicle sales.

### 🔋 Global EV Stock
Shows the total number of electric vehicles currently in use.

### 📊 EV Sales Share
Displays EV sales share as a percentage.

### 📈 Global EV Sales Trend (2010–2025)
Visualizes the historical growth of EV sales over time.

### 🌍 Top EV Markets
Ranks the leading countries based on EV sales.

### 📉 China vs India vs USA Comparison
Compares EV sales trends among the world's major EV markets.

### ⚡ BEV vs PHEV Distribution
Shows the market share of Battery Electric Vehicles (BEV) and Plug-in Hybrid Electric Vehicles (PHEV).

---

## 💡 Key Insights

- China dominates the global EV market.
- Global EV adoption accelerated significantly after 2020.
- BEVs account for the majority of global EV sales.
- India has emerged as one of the fastest-growing EV markets.
- Global EV stock has shown strong year-over-year growth.
